# Qani 🔒

Qani is a modern, secure full-stack security suite and password generator designed to provide robust cryptographic tools through a high-performance Spring Boot backend and an intuitive Tailwind CSS interface.

## Overview

Qani bridges the gap between powerful backend security architecture and user-friendly design. It delivers secure password generation capabilities, file-scanning utilities, and a resilient, stateless API built on modern enterprise standards.

## Core Features

🚀 **Cryptographic Generation:** Generates robust, high-entropy passwords tailored to user-defined security parameters.  
🛡️ **Security Suite:** Integrates file analysis and scanning capabilities with client-side hashing support.  
⚡ **Spring Boot 3 Architecture:** Powered by a fast, secure REST API leveraging stateless JWT authentication and granular CORS policies.  
🎨 **Modern Frontend UI:** Built with Tailwind CSS to deliver a sleek, fully responsive, and distraction-free user experience across all devices.  
🗄️ **Cloud-Native Persistence:** Connects seamlessly to a scalable PostgreSQL database via enterprise connection pooling.  

## Architecture & Technology Stack

* **Backend:** Java 17, Spring Boot 3, Spring Security, Spring Data JPA / Hibernate, PostgreSQL (Supabase)
* **Frontend:** Tailwind CSS, Modern JavaScript
* **Security & Auth:** Stateless token-based architecture, secure environment-based credential management
